# Testare pe telefon

Lista de verificat după fiecare build nou, pe un iPhone real.

## Descărcare
- [ ] Lipește un link de **playlist** → apare „PLAYLIST DETECTAT” cu numărul de melodii, durata și câte sunt deja în bibliotecă → **Descarcă N melodii noi**.
- [ ] **Descărcări**: procent, bară, MB/s; stări *Gata* / *Eșuat* (+ *Reîncearcă*) / *În așteptare*; **Pauză tot** / **Reia tot**.
- [ ] Ieși din aplicație în timpul descărcării → descărcarea continuă.
- [ ] Playlistul apare în **Playlisturi** cu eticheta **Din YouTube**.
- [ ] **Share → Nocturne** din aplicația YouTube deschide „Adaugă muzică” cu linkul.

## Redare
- [ ] Redă o melodie → **blochează telefonul** → la final trece singură la următoarea.
- [ ] **Ecran blocat** și **Control Center**: titlu, artist, copertă, timp, play/pauză, următoarea, anterioara, derulare.
- [ ] **AirPods**: o apăsare = play/pauză, două = următoarea, trei = anterioara. Scoți o cască → pauză.
- [ ] Apel telefonic sau Siri → pauză, apoi reia.
- [ ] Anterioara după mai mult de 3 s → reîncepe melodia.
- [ ] Închide complet aplicația și redeschide → ultima melodie, poziția și coada sunt restaurate.

## Sistem
- [ ] **Dynamic Island** (14 Pro și mai noi): compact (copertă + egalizator auriu), minimal (cu altă aplicație activă), extins la apăsare lungă.
- [ ] **Setări → Sistem → Card Live Activity** pornit → cardul apare pe ecranul blocat (toate modelele); oprit → dispare, rămâne doar playerul iOS.

## Limbă și date
- [ ] **Setări → Limbă**: Română → English → Русский, live, fără repornire. Live Activity urmează limba.
- [ ] Titlurile melodiilor **rămân neschimbate** după schimbarea limbii.
- [ ] **Editează detaliile** (⋮ sau „…” în Se redă acum) → titlul nou apare peste tot: listă, Se redă acum, ecran blocat, Control Center, Live Activity.
- [ ] **Versuri**: „…” → Versuri; linia curentă evidențiată, atingi o linie → sare acolo; merg offline după prima încărcare.
- [ ] **Fișiere → Pe iPhone → Nocturne → Music**: melodiile `.m4a` sunt vizibile.

## Layout
- [ ] Corect pe **SE** (buton Home), **notch**, **Dynamic Island** și **Pro Max**. Compară cu artefactul *screenshots* din Actions.
- [ ] Cu textul mărit din Setări iOS (Dynamic Type) nimic nu iese din ecran.
